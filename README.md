# Recipes App com TypeScript

Aplicação web desenvolvida em **React** e **TypeScript** para busca, filtragem, acompanhamento de preparo, favoritação e salvamento de receitas de comidas e bebidas.

## Sobre o Projeto

O **Recipes App** permite explorar receitas a partir de APIs externas, filtrar por categoria, ingrediente ou nome, acompanhar o progresso de preparo passo a passo e gerenciar receitas favoritas e concluídas no localStorage.

### Principais Recursos Implementados

- **Busca e filtragem de receitas**: Consulta por nome, ingrediente, primeira letra ou categoria para comidas e bebidas.
- **Detalhes e progresso de preparo**: Visualização de ingredientes, medidas e modo de preparo com acompanhamento de etapas em progresso.
- **Favoritas e concluídas**: Persistência de receitas favoritas e finalizadas com filtragem rápida e compartilhamento de link.
- **Tipagem estática e gerenciamento de estado**: Modelos de dados, respostas de API e estados globais tipados com **TypeScript**.

## Tecnologias Utilizadas

- **React**
- **TypeScript**
- **React Router**
- **CSS3**

## Como Executar Localmente

1. Clone este repositório:
   ``bash
   git clone [https://github.com/Nadi0301/project-recipes-app-ts.git](https://github.com/Nadi0301/project-recipes-app-ts.git)
   ``

2. Acesse a pasta do projeto:
   ``bash
   cd project-recipes-app-ts
   ``

3. Instale as dependências:
   ``bash
   npm install
   ``

4. Inicie a aplicação:
   ``bash
   npm start
   ``
